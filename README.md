# Assistente de Cuidados

O Assistente de Cuidados é um aplicativo com interface adaptada para dispositivos móveis que conecta famílias a cuidadores. As famílias podem buscar profissionais, consultar seus perfis, escolher datas disponíveis e solicitar uma contratação. Os cuidadores podem editar o perfil, organizar a disponibilidade e aceitar ou recusar solicitações.

O aplicativo permite acompanhar, cancelar e concluir contratações, além de consultar o histórico. A conclusão depende da confirmação da família e do cuidador. O painel administrativo reúne as contas cadastradas e o histórico geral de contratações.

## Tecnologias utilizadas

- **Frontend:** Ionic, Angular, TypeScript, HTML e SCSS.
- **Recursos mobile e ícones:** Capacitor e Ionicons.
- **Backend:** Java, Spring Boot, Spring Security e Spring Data JPA/Hibernate.
- **Autenticação:** JWT e BCrypt.
- **Banco de dados:** MySQL e TiDB Cloud.
- **Armazenamento de imagens:** Cloudinary.
- **Compilação e execução:** Node.js, npm e Maven.
- **Hospedagem:** Netlify no frontend e Render com Docker no backend.
